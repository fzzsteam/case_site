# 文旅 AIGC 案例站设计规格

## 目标

建设一个面向文旅客户的 AIGC 视频案例展示站，用于展示作品、说明服务能力、公开基础报价并引导微信咨询。首版使用 Next.js，案例数据由代码内的类型化静态配置维护，图片和视频存放在私有阿里云 OSS。

设计稿只作为水墨视觉、排版比例和氛围参考，不逐项复刻其中重复或低价值的卡片。网站优先保证案例浏览、视频播放和合作转化路径清晰。

- 精选案例：少量统一视频卡片，不保留设计稿中的独立超大播放器。
- 合作 CTA：跳转联系我们页。

删除设计稿中的四项数据墙、重复服务大卡和其他证明型卡片。

### 案例页

- 简短 Hero 和案例分类筛选。
- 响应式案例视频网格。

- 每个案例提供可静态生成的独立详情页，包含完整文字介绍和视频结构化数据。
- 分类首版来自静态配置，不引入后台。

删除价值卡片和重复的数据指标。页面主体只服务于找案例、看案例。

## 组件架构

- `SiteHeader`：桌面导航、移动端菜单和当前页面状态。
- `InkLandscape`：共享水墨场景，接收页面动效预设和可选前景图层。
- `BirdFlock`：轻量 SVG 鸟群和路径动画。
- `SectionHeading`：统一章节标题及金色装饰线。
- `ServiceCard`：首页核心服务卡。
- `CaseCard`、`CaseGrid`、`CaseDialog`：案例封面、网格和视频播放弹层。
- `CapabilityGrid`、`ProcessTimeline`：关于页能力及流程。
- `PricingCard`、`PricingGrid`：报价内容。
- `ContactPanel`、`SiteFooter`：咨询与品牌信息。

组件仅接收展示数据，不直接读取 OSS 凭证或签名媒体地址。页面负责组织区块，静态配置负责内容。

## 动效系统

全站采用同一套“山水入卷”动效语言，通过 `InkLandscape` 的 `motionPreset` 切换页面叙事：

- 首页 `converge`：左右近景向中间靠拢，远山产生反向微视差，云横向漂移，鸟群沿曲线飞行。
- 案例页 `river`：滚动时远、中、近景以不同速度横向移动；视频播放期间暂停非必要装饰动画。
- 关于页 `unfold`：使用遮罩从中心向两侧展开，流程线随滚动绘制，内容逐项显现。
- 联系页 `reveal`：薄云向两侧散开，随后依次显示报价与二维码；二维码自身保持稳定。

动效只使用 `transform`、`opacity` 和遮罩等合成友好属性。移动端减少图层位移和鸟群数量；系统启用 `prefers-reduced-motion` 时直接显示最终状态。动效失败或 JavaScript 未运行时，静态首屏仍须完整可读。

## 数据与 OSS 流程

案例静态配置中的封面和视频都只保存私有 OSS 相对路径，例如：

```ts
{
  slug: "museum-digital-film",
  title: "博物馆数字化",
  category: "museum",
  coverPath: "cases/museum/cover.webp",
  videoPath: "cases/museum/film.mp4"
}
```

服务端 OSS 模块从环境变量读取 Endpoint、Bucket、AccessKey ID 和 AccessKey Secret，验证相对路径后生成限时签名 URL。凭证只能用于服务端代码，不能进入 `NEXT_PUBLIC_*` 环境变量或客户端包。

OSS Bucket 中的封面、Open Graph 图片和视频全部保持私有。封面与分享图通过稳定的同源媒体代理 URL 提供：Next.js 服务端校验对象路径、读取私有 OSS，并返回带缓存策略的图片响应，因此浏览器、搜索引擎和社交平台不会接触 OSS 凭证或临时地址。页面不在初始 HTML 中暴露视频签名，用户点击播放时才请求临时链接，减少无效签名和网络开销。签名接口和媒体代理只接受配置中存在或符合允许前缀的对象路径，拒绝绝对 URL、路径穿越和未知前缀。视频签名默认有效期为 15 分钟，并允许通过服务端配置调整。

签名失败时，图片显示统一占位状态，视频卡显示“暂时无法播放”并允许重试；日志记录对象路径和错误类型，但不记录凭证或完整签名 URL。

## 视觉规则

- 主色使用深松石绿、宣纸米白和克制的鎏金色。
- 标题采用具有宋体气质的中文字体，正文使用清晰易读的中文字体；字体加载失败时仍保持可靠回退。
- 背景使用轻微纸张纹理，内容区留白大于设计稿，避免卡片堆叠。
- 视频封面是页面最强视觉重点，水墨装饰不得覆盖播放控制或正文。
- 可点击元素具备键盘焦点、明确悬停状态和足够触控尺寸。

## SEO

- 使用 Next.js App Router 和服务端组件输出可直接抓取的页面主体，不依赖客户端 JavaScript 才能读取标题、服务、报价或案例介绍。
- 首页、案例列表、案例详情、关于我们和联系我们分别定义唯一的标题、描述、canonical 和 Open Graph 信息。
- 提供 `sitemap.xml` 和 `robots.txt`，站点地图包含全部公开案例详情页。
- 案例详情页输出 `VideoObject` JSON-LD；全站输出 `Organization` JSON-LD，并使用真实品牌名称、Logo、联系方式和站点地址。
- 每个案例详情页包含唯一 slug、可索引文字简介、服务类型和稳定封面 URL。视频临时签名 URL 不写入结构化数据；`VideoObject` 使用稳定的详情页嵌入地址和封面地址。
- 页面使用单一明确的 `h1`、连续标题层级、语义化导航和正文；装饰性水墨图层使用空替代文本且不进入可访问性树。
- 动态 Hero 的核心文案始终存在于服务端 HTML 中，动画不得延迟或隐藏搜索引擎所需内容。

## 响应式与性能

- 桌面端充分呈现多层景深；移动端重排为单列并裁剪非关键远景。
- 首屏只预加载必要水墨图层和当前封面，其余媒体懒加载。
- 视频不自动播放、不默认下载完整文件；使用封面并在交互后加载。
- 分层 PNG 在不破坏透明边缘的前提下提供 WebP/AVIF 派生资源，保留源文件。
- 页面布局在媒体加载前预留尺寸，避免累计布局偏移。

## 验收与测试

- 单元测试覆盖案例配置校验、OSS 路径校验、签名成功及失败映射。
- 组件测试覆盖分类筛选、视频弹层打开/关闭、键盘操作和错误占位。
- 端到端测试覆盖四页导航、首页到案例/联系页的 CTA、案例播放请求和移动端菜单。
- SEO 测试覆盖页面 metadata、canonical、结构化数据、站点地图、robots 和案例详情静态参数。
- 验证私有 OSS 凭证不会出现在浏览器源码、网络响应或构建产物中。
- 在桌面和移动视口检查图层裁剪、文本可读性、二维码可扫描性及 `prefers-reduced-motion`。

## 首版范围外

- 内容管理后台和数据库。
- 在线询价或线索提交表单。
- 用户账号、收藏、评论和数据统计后台。
- 为设计稿中的每一个装饰卡片做一比一复刻。
