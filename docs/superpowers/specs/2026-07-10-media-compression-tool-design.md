# 媒体原位压缩工具设计

## 目标

为 `方直智胜-往期项目` 提供一个可重复运行的命令行工具，递归压缩图片和 MP4 视频，保持现有文件路径、文件名、扩展名与画面尺寸不变。工具执行后直接替换原文件，并准确汇报处理数量、压缩前后空间和节省比例。

## 范围

- 处理 JPEG、PNG 和 MP4。
- 不处理无法识别的文件以及其他格式。
- 不修改网站源码或媒体引用。
- 不主动缩小分辨率。
- 采用网页均衡质量：JPEG 使用适合网页的有损重编码；PNG 保持透明通道并重编码优化；MP4 使用 H.264 CRF 24、AAC 音频和 faststart。

## 工具结构与接口

工具作为项目内独立脚本运行，接收一个目标目录参数。实现按职责拆分为：媒体发现、单文件压缩、媒体有效性验证、安全替换、统计汇总。外部依赖为本机已有的 `ffmpeg` 和 `ffprobe`。

命令应支持正常执行和 dry-run。正常执行会修改目标文件；dry-run 只扫描并报告候选文件，方便检查范围。

## 处理流程

1. 递归扫描目标目录，按实际媒体类型与受支持扩展名筛选文件。
2. 在源文件同一目录创建唯一临时输出，避免跨文件系统替换风险。
3. 使用对应编码参数压缩，保留原画面尺寸；视频保留音频（若存在）。
4. 用 `ffprobe` 验证临时文件可读取，并确认至少存在预期的视频或图片流。
5. 比较临时文件与原文件大小。只有临时文件更小时才原子替换原文件；否则删除临时文件并保留原件。
6. 无论成功、跳过或失败，都清理临时文件并记录原因。
7. 最后重新统计目标目录总大小，输出扫描数、替换数、未变小数、失败数、压缩前后字节数、节省字节数和比例。

## 安全与错误处理

- 编码完成和验证成功之前绝不覆盖源文件。
- 替换只发生在新文件严格更小时。
- 单个文件失败不终止整批任务，错误进入汇总并保留源文件。
- 捕获中断信号并尽力清理临时文件。
- 不创建永久备份；用户已明确要求压缩后直接替换原文件。
- 未知格式文件保持不变。

## 验证

先在临时目录生成小型 JPEG、透明 PNG、含音频 MP4 和未知文件样本，验证：支持格式会被扫描；输出可由 `ffprobe` 读取；较大输出不会替换；未知文件不修改；统计前后一致；脚本重复运行不会导致文件变大。测试通过后再对目标目录执行，最后用 `ffprobe` 检查全部处理后媒体并独立计算最终目录空间。

## 完成标准

- 工具脚本保存在项目中，可再次运行。
- 目标目录内可获益的 JPEG、PNG、MP4 已安全原位替换。
- 所有处理后媒体可读取。
- 最终报告包含总共成功压缩的文件数、处理前总空间、处理后总空间及节省量。
