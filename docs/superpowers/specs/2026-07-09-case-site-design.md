# AI 文旅视频案例官网设计规格

## 目标

构建一个用于案例展示的文旅行业 AI 视频官网首屏。页面需要高保真还原 `render.png` 的视觉方向，并实现 `uiux.md` 中定义的核心交互。技术选型为 Next.js + React + Tailwind CSS + Framer Motion，SEO 以业务关键词为主，品牌词和案例词为辅。

核心搜索目标：

- 文旅宣传片制作
- 景区 AI 视频
- 博物馆宣传片
- AI 文旅视频创作
- 文旅视界
- 增城文旅视频案例
- 南阳汉画馆宣传片

## 范围

本阶段只做一个官网首页，突出两个内容：

- 案例展示
- 关于我们 / 联系合作

不做后台、真实表单提交服务、真实视频托管、独立案例详情页或多语言站点。联系表单提交先做前端校验和成功反馈。视频地址为空时显示“视频即将上线”；已有视频地址时使用原生 `<video>` 或可嵌入地址播放。

## 技术方案

采用 Next.js App Router。首页负责输出可索引的基础内容和 SEO metadata，交互密集的案例展示区域使用客户端组件。

主要依赖：

- Next.js / React：页面框架与服务端可索引 HTML
- Tailwind CSS：样式系统
- Framer Motion：入场、切换、弹窗和 hover 动效
- lucide-react：导航、播放、箭头、关闭等图标

建议结构：

```text
app/
  layout.tsx
  page.tsx
  globals.css
components/
  case-showcase.tsx
  case-card.tsx
  video-modal.tsx
  contact-modal.tsx
  site-header.tsx
data/
  cases.ts
public/
  images/
```

## 数据模型

案例内容集中维护，页面所有联动状态由 `activeCategory + activeIndex` 驱动。

```ts
type CaseCategory = 'promo' | 'ad'

interface CaseItem {
  id: string
  category: CaseCategory
  title: string
  subtitle: string
  description: string
  cover: string
  background: string
  videoUrl?: string
  seoKeywords: string[]
  status?: 'ready' | 'coming-soon'
}
```

默认数据：

- 宣传片：增城文旅、南阳汉画馆、更多案例、即将上线
- 广告片：景区活动广告、城市品牌广告、博物馆展览广告、即将上线

## 视觉设计

页面首屏为深色电影感大图背景，参考 `render.png`：

- 左上角品牌区：图形标识 + “文旅视界 / AI 文旅视频创作”
- 顶部导航：案例展示、关于我们、联系合作，使用统一文字导航样式，项目之间用细竖线分隔
- 左侧主视觉：大标题、副标题、短描述、观看作品集按钮
- 左下角：轻量关于我们模块，不做独立大板块
- 右侧：宣传片 / 广告片 Tab 和横向案例卡片组
- 底部：左右箭头、分段进度条、当前页码

色彩保持深色背景、灰白文字、金色点缀。金色只用于 Tab 激活态、按钮、进度条、页码和少量边框高亮，避免大面积铺色。

字体使用系统中文字体栈和衬线标题组合，保证现代、克制、可读。标题可使用 serif fallback 营造文旅感，但正文保持清晰。

## 交互设计

首屏载入：

1. 背景图淡入
2. 深色遮罩同步出现
3. 顶部导航下移淡入
4. 左侧标题和文案分层滑入
5. 右侧卡片错位滑入
6. 底部进度条、箭头、页码最后出现

案例切换：

- 点击卡片或底部箭头会更新当前案例
- 当前案例驱动背景、左侧文案、卡片状态、页码和进度条
- 背景使用交叉淡入，新背景带轻微 scale 过渡
- 文案使用向下淡出、向上淡入
- 卡片横向滑动并突出当前项
- 左右箭头循环切换

分类切换：

- 点击“宣传片 / 广告片”切换分类
- Tab 下划线滑动
- 卡片组淡出下移后切换数据，再淡入上移
- 默认选中新分类第一个案例
- 背景、文案、页码、进度条同步更新

弹窗：

- 主按钮和卡片播放按钮打开视频弹窗
- 页面背景暗化并轻微模糊
- 视频弹窗从 `scale(0.96)` 淡入到 `scale(1)`
- 关闭时暂停视频并恢复页面
- 联系合作导航打开联系弹窗，包含姓名、手机号、项目类型、需求描述和提交需求按钮

自动轮播：

- 每 6 秒切换下一个案例
- 鼠标 hover 卡片区域、用户操作、视频弹窗打开时暂停或重置计时
- 关闭弹窗后恢复

移动端：

- 顶部导航折叠菜单
- 标题区位于上方
- 案例卡片横向滑动并吸附
- Tab 保持在卡片上方
- 页码和进度条位于卡片下方
- 关于我们移动到案例区域下方

## SEO 设计

首页需要服务端输出完整 metadata：

- `title`：文旅宣传片制作与 AI 文旅视频案例 | 文旅视界
- `description`：围绕文旅宣传片、景区 AI 视频、博物馆宣传片、城市文旅广告片的案例展示和合作转化
- `keywords`：业务词为主，品牌词和案例词为辅
- canonical URL 预留配置
- Open Graph 和 Twitter metadata

页面语义化：

- `header`：品牌和导航
- `main`：案例展示核心内容
- `section`：案例展示、关于我们
- `article`：每个案例卡片
- 表单字段使用 `label`，按钮有明确 `aria-label`

结构化数据：

- `Organization`：品牌名称、服务描述、官网 URL、联系合作入口
- `CreativeWork` 或 `VideoObject`：为可播放案例输出名称、描述、缩略图、分类和关键词

图片：

- 背景和封面使用可描述的文件名
- 案例封面提供中文 alt，例如“增城文旅 AI 宣传片山水城市夜景画面”

## 错误与降级

- 视频地址为空时，播放按钮仍可打开弹窗并显示“视频即将上线”
- 即将上线卡片不可播放，只展示状态和查看箭头
- 联系表单提交先做前端校验和成功提示，不依赖后端
- 用户开启减少动态效果时，降低或关闭视差和大幅位移动画
- 图片加载失败时使用深色渐变背景兜底

## 验收标准

- 首屏视觉接近 `render.png`：深色电影感、左文案、右卡片、底部进度和页码布局完整
- 案例切换时背景、文案、卡片、页码、进度条全部联动
- 宣传片 / 广告片切换有克制过渡，并重置到新分类第一个案例
- 视频弹窗和联系弹窗可打开关闭
- 自动轮播不会打断 hover、点击和弹窗操作
- 移动端可横向浏览案例，文字不重叠
- SEO metadata、语义化内容、结构化数据存在
- `npm run build` 通过
- 使用浏览器检查桌面和移动端无明显布局溢出或遮挡
