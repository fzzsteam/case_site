# 首页山水画图层还原设计

## 目标

以 `public/ink/origin.jpg` 为唯一视觉基准，在现有横向首页 Hero 中还原原画下半部的山水主体。六张透明 PNG 图层需要在山峰、松树、亭台、河道和远景建筑上与原图对应区域重合，避免继续用互不关联的 `vw` 尺寸、透明度和滤镜进行主观拼接。

本次只调整首页 Hero 的山水构图，不改首页文案、案例内容、导航结构或后续章节。

## 构图策略

建立一个与原画有效画幅一致的内部坐标系。先识别并排除 `origin.jpg` 上下的黑色截图区域，再确定横向 Hero 需要展示的山水主体裁切窗口。六张 PNG 依据其透明像素边界及原图对应内容，换算回同一内部画布中的位置和尺寸。

浏览器只对统一画布做整体缩放和裁切；图层之间不再各自响应视口宽度。这样不同桌面宽度下，山峰、亭台与河道仍保持原画中的相对关系。

桌面端使用横向裁切窗口，保留主体山水并将原画上部大面积留白排除在首屏之外。移动端可调整统一画布的观察窗口以保留关键景物，但不改变六层内部坐标。

## 图层表现

- 六张切层素材保留原始颜色和 Alpha 通道。
- 默认不使用 `mix-blend-mode`、饱和度、对比度滤镜或额外降透明度。
- 图层层级以原画遮挡关系为准：远景在后，中景山体与河道居中，左右近景山石、松树和亭台在前。
- 云雾和飞鸟等现有装饰只有在不妨碍原画重合时才保留；若与原图已有内容重复或改变色调，则从 Hero 中移除。
- 首页文案继续置于画面左侧相对留白处，并维持足够对比度；不通过大面积遮罩破坏原画颜色。

## 动效

初始入场和滚动动效只能对统一山水画布做轻微整体位移，或对图层做幅度极小且最终回归基准位置的位移。任何时刻都不得通过独立缩放改变图层间的构图关系。

启用 `prefers-reduced-motion` 时直接显示准确的静态还原结果。动画关闭后应与视觉验收基准完全一致。

## 实现边界

- 首页继续复用当前 `HomeExperience` 结构。
- 将 Hero 图层布局参数集中维护，避免在多个历史 CSS 规则中重复覆盖。
- 清除或覆盖仅针对旧素材名称、旧拼接方案的 Hero 规则，但不处理与本次无关的全站样式债务。
- 保留源图和六张 PNG，不对用户素材进行破坏性修改。

## 验收方法

1. 从 `origin.jpg` 提取有效画幅及目标横向裁切区域。
2. 在固定桌面视口截取动画结束后的首页 Hero。
3. 将截图中的山水区域与原图目标裁切进行半透明叠加或差异比对。
4. 检查远景建筑、左右山脊、前景松树、右侧亭台和河岸轮廓是否重合。
5. 分别检查桌面宽屏、普通桌面和移动端，确认裁切变化不会拆散构图。
6. 运行相关组件测试和首页测试，确认文案、链接以及减少动态效果模式仍正常。

验收优先级依次为：图层几何重合、遮挡层级、原始色调、文案可读性、轻量动效。若动效与准确还原冲突，以静态准确还原为准。

## 不在本次范围

- 将完整竖幅原画塞入首页或显著增加 Hero 高度。
- 重新切割或 AI 重绘原画素材。
- 重做首页其他章节。
- 为追求视差效果而重新艺术化排列六张图层。
